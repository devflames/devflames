## 🧩 ApkayA Ecosystem

> Three independent initiatives, with distinct purposes, architectures, audiences, and build stages. The projects are related through the ecosystem, not one interchangeable product.

| Project | Focus | Audience | Repository / Source | Status |
|---|---|---|---|---|
| **ApkayASocial** | Social-platform product & infrastructure | Customer-deployable platform operators | Commercial licensed direction; license undecided | Pre-deployment · active build |
| **ApkayA Web3Platform** | On-chain developer infrastructure | Blockchain application developers | Public official repository | v0 roadmap complete through Phase 9 |
| **ApkayA Enterprise Platform** | Security, cloud, hosting, billing & AI control plane | MSPs and enterprise resellers | Private source; public docs & SDK | v6.0.0 · README-stated Production Ready |

**Status labels reflect the supplied project descriptions, not independent deployment verification.**

### ApkayASocial — Foundation & Boundaries

- Latest supplied README reports 1,768 tests across five suites.
- Core identity, profiles, social graph, posts, feeds, messaging, notifications, media, forums, blogs, jobs, crowdfunding, games and admin foundations are described as implemented.
- Community web UI is pending; commerce is shared-contract-only; streaming, podcasts, creator economy, marketplace, AI, native mobile and Web3 are not shipped.
- Security foundations include Argon2id hashing, short-lived access JWTs, TOTP 2FA, rate limiting, privacy controls and signed media URLs.
- Deployment is parked by owner direction; license-server deployment and production verification remain outstanding.

### ApkayA Web3Platform — Developer Infrastructure

- Engine: durable Postgres-backed transaction queue, backend wallets, signing, send and status APIs.
- Insight: EVM event indexing and read APIs for balances, NFTs and transfers.
- Dashboard, CLI, TypeScript SDK, React Native / Flutter SDKs, wallet connect, SIWE, Coinbase CDP Bridge widgets, and Solidity templates.
- API keys are hashed and revocable individually.
- Docker Compose and localhost addresses are local development references, not public endpoints.

### ApkayA Enterprise Platform — Commercial Control Plane

- Repository-reported 69 dashboard pages, 40+ API modules, 101+ Prisma models, 14 cloud adapters and 241 API unit tests.
- WAF, threat monitoring, RBAC, multi-tenancy, cloud/hosting management, billing, reseller tools, signed plugins/themes, licensing and AI operations.
- Architecture is separated across Next.js dashboard, NestJS API, PostgreSQL/Prisma, Redis/BullMQ, license services and deployment tooling.
- The source is private; public documentation and SDK are separate from the platform source.
